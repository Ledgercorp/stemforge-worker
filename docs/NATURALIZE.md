# StemForge Naturalize

`naturalize` is a non-destructive **Naturalness / Authenticity** enhancement. It restores low-level pitch, amplitude, and phase movement without presenting itself as a creative modulation preset or an AI-detection/evasion tool.

## Agent behavior

- Call with `action: "naturalize"`.
- `mode: "auto"` is the default.
- Auto mode selects Surgical Naturalize when a vocal stem is supplied and falls back to Quick Naturalize otherwise.
- Explicit Surgical mode can run Demucs two-stem vocal separation when `separate_if_needed` is true.
- `intensity` accepts `0.0–1.0`; percentages such as `35` are also accepted.
- The source is never overwritten. By default StemForge publishes both the processed WAV and a PCM A/B reference of the original.
- The report records the nominal and effective depths, resolved mode, reconstruction decision, safety comparison, and measured naturalness characteristics.
- Autonomous `full_pass` jobs can opt in with `naturalize: true`, a mode string, or a configuration object. StemForge uses the already-materialized stems, runs Naturalize before mastering, and refuses to continue if the Naturalize safety gate fails.

## Mandatory processing order

1. Vibrato: 15 Hz, nominal depth 10
2. Tremolo: 15 Hz, nominal depth 10
3. Vibrato: 10 Hz, nominal depth 10
4. Flanger: 1 ms delay, 0.90 modulation, nominal depth 9
5. Light denoise after all modulation

The nominal depth values are preserved in the report. `intensity` scales their effective depth so the user can trade naturalness against source fidelity.

## Quick Naturalize

```json
{
  "action": "naturalize",
  "audio_url": "https://example.test/mix.wav",
  "artist": "sounddecay",
  "song": "Example",
  "mode": "quick",
  "intensity": 0.35
}
```

The complete cocktail is applied to the full mix. The post-modulation denoise is deliberately conservative, followed only by level preservation and non-limiting peak safety.

## Surgical Naturalize

```json
{
  "action": "naturalize",
  "audio_url": "https://example.test/mix.wav",
  "mode": "surgical",
  "intensity": 0.35,
  "stems": [
    {"name": "Lead Vocals", "url": "https://example.test/vocals.wav"},
    {"name": "Instrumental", "url": "https://example.test/instrumental.wav"}
  ]
}
```

The vocal receives a more assertive version of the chain. The instrumental receives lighter modulation plus conservative level preservation. The stems are recombined and the full mix receives the final gentle denoise.

Before accepting a supplied instrumental stem, StemForge tests whether vocal + instrumental safely reconstruct the source. If the reconstruction fails, it derives the instrumental anchor as `master - vocal`. This keeps the original mix coherent while still applying a genuine vocal/instrumental delta treatment.

## Autonomous full-pass use

```json
{
  "action": "full_pass",
  "master_url": "https://example.test/master.wav",
  "stems": [
    {"name": "Lead Vocals", "url": "https://example.test/vocals.wav"},
    {"name": "Bass", "url": "https://example.test/bass.wav"},
    {"name": "Drums", "url": "https://example.test/drums.wav"}
  ],
  "naturalize": {
    "mode": "auto",
    "intensity": 0.35,
    "retain_original": true
  }
}
```

The full-pass agent performs stem integrity analysis first. Naturalize then selects Surgical mode when a vocal stem is present, or Quick mode otherwise. Only a completed, safety-approved Naturalize render is handed to mastering. The full-pass report records whether Naturalize was applied, its resolved mode, nominal and effective parameters, anchor decision, measured characteristics, and safety comparison.

## Technical rationale

- Vibrato restores low-level pitch micro-movement.
- Tremolo restores organic amplitude movement.
- Flanging contributes subtle phase behavior associated with physical recording paths.
- Denoising occurs after modulation so the newly introduced micro-variations are not removed before they can contribute to the result.

## Output and safety

Naturalize rejects non-finite audio, clipping, excessive source deviation, derivative/discontinuity growth, and meaningful high-frequency artifact growth. High-band comparisons are noise-floor aware: microscopic interpolation residue is logged as a raw diagnostic but cannot be mistaken for audible static.

The processing report includes before/after metrics, waveform correlation, level-matched residual, crest-factor change, spectral/derivative comparisons, the exact processing order, and an agent log for downstream reasoning.

Naturalize does not determine whether audio was generated by AI, does not guarantee any origin classification, and must not be described as a detection or concealment tool.
